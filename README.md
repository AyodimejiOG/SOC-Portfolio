# Investigation Methodology

Across all investigations in this portfolio, I follow a structured SOC investigation workflow:

1. Identify the alert or suspicious activity  
2. Collect relevant logs and telemetry  
3. Analyse patterns and anomalies  
4. Map findings to known attack techniques  
5. Assess severity and potential business impact  
6. Recommend containment or escalation actions  
7. Document findings clearly and professionally  

This approach mirrors the investigation processes commonly used in **enterprise Security Operations Centres**.
