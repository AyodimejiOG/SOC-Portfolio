# February 2026 – Enterprise Cloud Security Assessment (Microsoft Azure)

## Overview

In February 2026, I participated in a Cloud Security sprint focused on assessing the security posture of a simulated enterprise environment hosted in Microsoft Azure.

The objective of this engagement was to evaluate how effectively cloud security controls could be implemented, monitored, and used to detect and respond to modern threats. The environment was designed to reflect real-world enterprise risks, including misconfigurations, excessive privileges, limited visibility, and delayed incident response.

This sprint provided hands-on experience in cloud security, security monitoring, and SOC-aligned detection and response using Azure-native tools.

---

## Key Responsibilities

During this sprint, I contributed to the assessment and documentation of cloud security controls across multiple domains.

My involvement included:

- Supporting the implementation and validation of Azure security configurations  
- Analysing how security controls impact detection and response capabilities  
- Contributing to the overall security assessment report  
- Interpreting technical findings in relation to business risk and security posture  

This experience allowed me to understand how cloud security integrates with SOC operations and organisational risk management.

---

## Cloud Security Activities

### Identity & Access Management (RBAC)

I worked with role-based access control (RBAC) to implement structured access management within the environment.

This involved:

- creating user groups with different privilege levels  
- assigning roles based on least privilege principles  
- managing access to cloud resources  

Key learning:

Effective identity governance is critical in preventing privilege abuse and reducing attack surface.

---

### Network Security & Segmentation

I explored how Azure networking controls can be used to secure workloads.

This included:

- configuring Network Security Groups (NSGs)  
- implementing Application Security Groups (ASGs)  
- controlling inbound and outbound traffic  

Key learning:

Proper network segmentation significantly reduces the risk of lateral movement within cloud environments.

---

### Azure Firewall & Traffic Control

I participated in configuring Azure Firewall to enforce controlled network communication.

This involved:

- defining application and network rules  
- restricting outbound traffic  
- validating secure communication paths  

Key learning:

Controlling outbound traffic is just as important as protecting inbound access.

---

### Cloud Monitoring & Logging

I worked with Azure Monitor and Log Analytics to enable centralized visibility.

This included:

- configuring data collection rules (DCRs)  
- collecting system and security logs  
- analysing telemetry for security insights  

Key learning:

Without proper logging, effective threat detection and incident response are not possible.

---

### Threat Protection (Microsoft Defender for Cloud)

I explored how Microsoft Defender for Cloud enhances security posture.

This involved:

- enabling advanced threat protection features  
- reviewing vulnerability assessments  
- analysing security recommendations  

Key learning:

Continuous posture management is essential for identifying and addressing cloud security risks.

---

### Attack Surface Reduction

I implemented Just-in-Time (JIT) access to secure virtual machines.

This helped:

- reduce exposure of management ports  
- limit access to approved time windows  
- prevent brute force attacks  

Key learning:

Reducing unnecessary exposure is a key principle of modern cloud security.

---

### SIEM & Incident Response (Microsoft Sentinel)

I worked with Microsoft Sentinel to simulate SOC operations in a cloud environment.

This included:

- onboarding data sources  
- creating detection rules  
- generating alerts  
- exploring automated response using playbooks  

Key learning:

Centralised detection and automated response significantly improve incident response efficiency.

---

## Key Security Insights

Through this assessment, several important insights emerged:

- Excessive privileges remain a major security risk without continuous governance  
- Centralised visibility is essential for early threat detection  
- Misconfigurations are a leading cause of cloud vulnerabilities  
- Automation is critical for scalable security operations  
- Effective cloud security requires both technical controls and skilled analysts
